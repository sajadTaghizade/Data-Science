# Data Science

This repository contains the coursework and the final data science project.

## 📦 Final Project → [`Final_Project/`](Final_Project/README.md)

The complete, end-to-end **final project** lives in **[`Final_Project/`](Final_Project/README.md)** —
a Stack Overflow C++ **similar-question recommender**, organized into three
self-contained, independently runnable phases:

- **[Phase 1](Final_Project/Phase1/README.md)** — data collection (crawler + dataset)
- **[Phase 2](Final_Project/Phase2/README.md)** — database, EDA, pipeline, CI, Docker/Kubernetes
- **[Phase 3](Final_Project/Phase3/README.md)** — model development, evaluation, train/predict pipelines, MLflow

Start with the [`Final_Project/README.md`](Final_Project/README.md) for the overview and quickstart.

## Course assignments

The `CA0/`–`CA5/` folders contain the individual course assignments and are
independent of the final project.
